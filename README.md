**seresta** is a tool suite for parsing and analyzing search results on web. Basic idea is having a framework for interacting with paginated results or SPAs helps many complex web automation scenarios. I started this project before agentic browser use was a thing but still time and time again I see this approach also has some upsides compared to agentic browser. (Actually I use a hybrid approach when things get tough.)

It has two parts:
1. serespar: Basic framework powered by playwright allows you to write apps which do web scraping, extracting structured data or interacting with the web site.
2. Analysis part: Tools for analysing extracted info from different web sites. (I am yet to upload it.)

It is in mono-repo fashion, as in, it also includes any projects I'm working on. Feel free to use them.
